# Trading Worker 产品介绍视频设计

**日期：** 2026-08-08  
**状态：** 已确认，待实施  
**受众：** 个人投资者，以及希望快速理解桌面产品能力的潜在用户。

## 目标

制作一支可用于官网、发布演示和横版视频平台的中文产品介绍片。视频用真实的产品界面讲清 Trading Worker 从市场观察、AI 研究到回测验证和因子探索的工作流，而非逐项罗列功能。

## 成片规格

- 画幅：横版 16:9，1920 × 1080。
- 帧率：30 fps。
- 时长：约 54 秒（1,620 帧）。
- 声音：无旁白；使用可商用或项目已授权的电子氛围配乐。
- 文案：中文标题和简短辅助文字。
- 视觉：深色金融终端基调，以湖蓝和紫色的发光、遮罩与扫光作为转场语言。

## 创意方向

采用“工作流脉冲”而不是纯功能巡礼或抽象数据终端风格。每段真实 UI 都由一个问题或动作推进，最终形成“从市场信息，到可验证的研究”的完整叙事。截图是产品真实性的主体；程序化图层仅用于建立节奏、聚焦信息和串联场景。

## 素材与真实性边界

- 所有主 UI 均来自仓库的 `assets/` 截图；不得伪造操作结果或把示例指标变成性能承诺。
- “本地”指桌面控制台管理本机研究服务，服务监听回环地址；不得描述为所有模型与数据处理均离线。业务 WebUI 在默认浏览器打开。
- 市场截图内含样例/特定日期行情；不得使用“实时”“全覆盖”或“投资推荐”等表述。
- 视频不将实盘交易作为卖点，不演示券商写入、下单或自动交易。
- 回测段将保留研究风险提示；示例收益、夏普或基准数据只作为界面内容，不作旁白或标题主张。
- Alpha 段只说“内置多类预构建量化因子”，避免因仓库中的数量口径不一致而使用精确数字。

## 实现结构

在独立的 Remotion 项目中实现，避免向现有前端产物添加运行时依赖。

- `Root`：声明 1080p、30 fps、54 秒的产品片 Composition。
- `ProductIntro`：按时间轴编排六个场景与全局背景/配乐。
- `SceneFrame`：复用截图取景、圆角窗口、标题和安全辅助文案。
- `FrameMotion`：以 `useCurrentFrame()`、`interpolate()` 和 `spring()` 定义入场、推近、裁切与退出；不使用 CSS transition 或 animation。
- `public/`：放置经复制或优化后的 UI 截图、图标和配乐，并通过 `staticFile()` 引用。

## 交互与数据流

视频是完全确定性的离线渲染：每帧只由 Remotion 当前帧、Composition 配置和本地静态素材决定。它不请求产品 API、不启动本地研究服务、不读取用户账户或交易数据。缺少音乐时，画面应可无声渲染，且标题、转场和时长保持不变。

## 验证标准

- TypeScript/Remotion 构建无错误。
- 在 0s、8s、20s、32s、43s 和 52s 各渲染一帧，检查文案、裁切、安全提示和结尾可读性。
- 渲染一份 H.264 MP4，在播放器中检查场景顺序、无黑帧、无截断标题、无叠层闪烁与配乐同步。
- 人工复核所有宣传语符合上节真实性边界，尤其是本地运行、市场数据、回测和 Alpha 描述。

## 非目标

- 不添加旁白、字幕转录、人物出镜或合成语音。
- 不制作实盘交易、收益保证或投资建议内容。
- 不改动既有 React 前端、Python 后端或 Tauri 桌面应用行为。
