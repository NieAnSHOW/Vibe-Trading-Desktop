# 启动引导与账户导航收敛设计

## 目标

将控制台根页面（`/`，当前为 `ConsolePage.vue`）调整为应用启动引导页。它负责首次安装、环境异常修复和服务启动失败恢复；环境正常时应用自动启动后端并直接进入研究页。账户和会员相关内容集中到 `ProfilePage.vue`，控制台与研究页的“环境”导航入口删除。

## 用户可见行为

### 启动状态机

应用每次启动按以下规则处理：

| 环境状态 | 行为 |
| --- | --- |
| `ready` | Rust 启动服务，健康检查通过后嵌入研究页 |
| `not_installed` / `incomplete` | 打开控制台引导页，展示安装或修复操作 |
| 环境检查失败 | 保留在引导页，展示可读错误和重试入口 |
| 首次安装完成 | 引导页确认环境就绪后启动服务并进入研究页 |
| 服务启动失败 | 保留在引导页，展示错误，允许再次启动或修复 |

环境异常时，后续每次启动都进入引导页，直到修复并重新安装成功。正常环境不再等待用户选择，自动启动行为也不再由用户配置。

### 页面职责

- `ConsolePage.vue` 保留 `/` 路由，但收敛为启动引导、安装/修复、启动失败恢复页面。
- `ProfilePage.vue` 承担账号身份、会员等级/有效期、权益、额度刷新、会员变更提示、客服/打赏入口和退出登录。
- `SettingsPage.vue` 移除“启动时自动启动服务”开关及其设置读写；保留主题配置、日志/运行环境维护和手动环境检查修复工具。

## 架构与数据流

### Rust 启动门控

`src-tauri/src/main.rs` 的启动流程继续负责首次运行目录准备、环境检查和 sidecar 生命周期，但启动条件改为“环境状态为 `Ready` 即启动”，不再读取用户可修改的 `autostart_service` 值。服务启动并通过健康检查后，复用现有 WebUI embed 流程进入研究页。

旧设置字段、IPC command 和兼容读取可按现有调用关系收敛删除；若为兼容旧配置保留字段，也不得让其阻断 `Ready` 环境的自动启动。

### 引导页安装完成

引导页继续监听 bootstrap 事件。收到成功退出事件后刷新环境状态；确认状态为 `ready` 后调用现有 service store 的启动流程，由该流程负责启动服务并打开 WebUI。安装失败、状态刷新失败或服务启动失败均停留在引导页并显示错误。

### 账户内容迁移

从 `ConsolePage.vue` 移出会员面板所需的状态、刷新函数、重启刷新流程、二维码对话框和模板，迁移到 `ProfilePage.vue`，复用现有认证、服务和 busy 状态模式。迁移后根页面不再展示账户/会员面板，避免启动引导和个人中心职责交叉。

## 导航调整

- 控制台 `Rail.vue` 删除 `environment` rail key、环境按钮和专用图标；账户、研究、主题、设置保留。
- 研究页 `DesktopShellRail.tsx` 删除环境按钮和对应 telemetry；账户、研究、设置保留。
- `src-tauri/console-app/index.html` 的预渲染 rail 同步删除环境节点，并将默认高亮改为中性/引导状态，避免 Vue 挂载前闪现旧菜单。
- 研究按钮在服务未运行时仍回到控制台 `/`，此时 `/` 的语义是引导/修复页而不是环境导航。
- `ShellConsolePage = "console"` 及托盘/崩溃返回控制台能力保留，作为隐藏恢复入口，不再由 rail 直接暴露。
- 清理不再引用的 `layout.rail.environment` 多语言文案，并同步修正文档注释。

## 错误处理与兼容性

- 所有启动、安装和修复动作继续使用现有 busy/错误展示，防止重复触发。
- 正常环境启动失败不得自动跳入空白研究页；必须保留引导页可见并允许重试。
- 退出登录后的回退仍指向 `/`，由引导页根据环境状态决定继续修复或再次启动。
- 不删除底层控制台根路由、托盘回退和 `desktopShell` 的 root URL 兼容路径。

## 验证范围

- Vue 控制台页面测试：首次未安装显示安装，安装成功后自动启动，失败时留在引导页；账户内容位于 Profile。
- Rail 测试：控制台和研究页均不存在环境入口，研究未运行时仍回到 `/`。
- Settings 测试：不再渲染或调用 autostart 开关。
- Rust 测试：`Ready` 环境不受旧 autostart 配置阻断，非 `Ready` 不自动启动。
- 前端 TypeScript/Vite 构建与 console-app 测试通过。
